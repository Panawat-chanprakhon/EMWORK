# EMWORK Fullstack Developer Test

## Specialized: Food Delivery Platform

Repository นี้เป็นคำตอบสำหรับแบบทดสอบ Fullstack Developer โดยแยกคำตอบตามโจทย์ทั้งหมด 7 ข้อ

## Files

1. `Question1_Assign_Rider.js`  
   การเลือก Rider จากระยะทาง ความใหม่ของ Location, Rating และ Fallback Logic

2. `Question2_Restaurant_Average_Order_Value.sql`  
   SQL สำหรับหา Top 3 Restaurant ตาม Average Order Value ในแต่ละ Category

3. `Question3_Place_Order.js`  
   การจัดการ Inventory Race Condition ด้วย Atomic Update และ Transaction

4. `Question4_Live_Tracking.md`  
   การออกแบบ Real-time Rider Tracking

5. `Question5_Dynamic_Incentive.md`  
   Dynamic Incentive และ Cancellation Log สำหรับวิเคราะห์พฤติกรรมการยกเลิกงาน

6. `Question6_AI_Delivery_Time.md`  
   AI Prompt สำหรับประมาณ Delivery Time พร้อม Validation และ Fallback

7. `Question7_Dynamic_Pricing.md`  
   Dynamic Pricing Architecture และ Hard-coded Pricing Guardrails
